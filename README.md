# Gestão de Faturas — Controlo de Assinaturas

Repositório de publicação da aplicação PWA de controlo administrativo de faturas.

**Nunca adicionar faturas, PDFs de clientes, cópias de segurança ou dados pessoais ao repositório.**

A publicação é feita através de um único arquivo `gestao-faturas-site.zip` e de uma rotina automática GitHub Actions. A aplicação publicada é pública; apenas os dados registados localmente no navegador permanecem no dispositivo.
